# AgentLens AI Roadmap

## v0.1 MVP

- Decorator-based tracing
- SQLite trace store
- CLI init, list-runs, report, eval
- YAML eval format
- Example tool-using agent
- Tests and CI

## v0.2 Developer usefulness

- HTML report
- Run detail view
- Trace timeline
- Baseline/latest comparison
- Better eval schema
- GitHub Action for agent regression gates

## v0.3 Framework integrations

- OpenAI wrapper
- LangChain callback handler
- LangGraph example
- Bedrock example
- CrewAI example

## v0.4 Production-readiness signals

- Token and cost tracking
- Latency percentiles
- Error classification
- Retry tracking
- OpenTelemetry export
- Postgres backend

## v1.0 Goal

A lightweight toolkit that AI engineers can install in minutes to debug, evaluate, and regression-test agent behavior before shipping to production.
